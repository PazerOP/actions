# Actions

A collection of GitHub Actions.

## [tab-check-action](./tab-check-action)

Enforces consistent indentation (tabs or spaces) in code files.

```yaml
- uses: PazerOP/actions/tab-check-action@v1
```

## [no-scripts-action](./no-scripts-action)

Ensures package.json files don't have scripts sections (use justfiles instead).

```yaml
- uses: PazerOP/actions/no-scripts-action@v1
```
